# agent-skills

A collection of autonomous AI agents and their skills.

## Structure

- `browser-agent/` – browser automation agent and its skills
- `coding-agent/` – autonomous coding agent (kernel, workers, brain, tests)
- `scripts/` – execution and contract verification scripts
- `web_agent.py` – Playwright-based web agent using opencode as the reasoning backend

## Quick start

```bash
pip install -r coding-agent/requirements.txt
python web_agent.py
```

See `HOW_IT_WORKS.md` and `QUICK_REFERENCE.md` for more details.
