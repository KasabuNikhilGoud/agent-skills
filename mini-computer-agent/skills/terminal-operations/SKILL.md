# Terminal Operations

## Steps
1. Use open_app to launch terminal
2. Use focus_window to ensure terminal is active
3. Use type_text to enter commands
4. Use press Return to execute
5. Use see_windows to check for new windows
6. Use screenshot to capture output if needed

## Best Practices
- Chain commands with && or ;
- Use | to pipe output
- Use > or >> to redirect output
- Check command output before proceeding
- Use run_command for non-interactive commands
