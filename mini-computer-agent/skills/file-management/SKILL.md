# File Management

## Steps
1. Use open_app to launch terminal (gnome-terminal, xfce4-terminal)
2. Use type_text to enter file commands (ls, cp, mv, rm, mkdir)
3. Use press Return to execute commands
4. Use see_windows to verify terminal is active
5. Use run_command for quick file operations when available

## Common Commands
- `ls`: List files in current directory
- `cd <path>`: Change directory
- `cp <src> <dest>`: Copy file
- `mv <src> <dest>`: Move/rename file
- `rm <file>`: Delete file
- `mkdir <name>`: Create directory
- `cat <file>`: View file contents

## Safety
- Always verify file paths before delete operations
- Use dry-run mode first if uncertain
