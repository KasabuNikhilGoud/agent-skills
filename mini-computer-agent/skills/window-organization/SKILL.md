# Window Organization

## Steps
1. Use list_apps to see all running applications
2. Use get_screen_geometry to understand available space
3. Use focus_window to activate target window
4. Use move_window to position windows
5. Use resize_window to adjust window sizes
6. Use focus_app to switch between applications

## Common Layouts
- Side by side: Two windows at half screen width
- Stacked: Windows stacked vertically
- Grid: Multiple windows in a grid pattern

## Tips
- Move windows before resizing for better control
- Use drag for precise positioning
- Close unused windows to reduce clutter
