# Web Browsing

## Steps
1. Use open_app to launch the browser (firefox, chromium)
2. Wait for browser window to appear
3. Use focus_window to ensure browser is active
4. Use click to interact with address bar or links
5. Use type_text to enter URLs or search terms
6. Use press Return to navigate
7. Use scroll to page through content
8. Use screenshot to capture current state if needed

## Tips
- Always verify the browser launched before typing
- Use list_apps to check which browser is available
- Click address bar first (usually top of window) before typing URLs
- Press Ctrl+L (or Command+L on macOS) to focus address bar quickly
